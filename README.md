# 双色球历史数据下载与整理工具（SSQ History Data Tool）

[English](README_EN.md) · [安装与排错](docs/TROUBLESHOOTING.md)

一个轻量的 Python 数据整理工具：从公开网页获取双色球历史数据，清洗并拆分为可筛选的字段，生成 Excel / CSV / TXT 文件，并附带简单的描述性统计。**不预测号码、不推荐选号、不计算投注方案。**

> **说明**：本项目与中国福利彩票机构及数据来源网站均无隶属关系。历史数据仅供查询、整理和学习；实际开奖号码请以官方公告为准。来源网站展示的“模拟开机号”并非官方开奖号码，项目会将其与正式奖号分别保存。

## 主要功能

1. **获取历史数据**：从 [乐彩网双色球历史页面](https://www.17500.cn/chart/ssq-kjh.html)尝试获取历史开奖表。先尝试直接 HTTP 请求，必要时回退至 Edge / Chrome 浏览器自动化。
2. **拆分号码列**：将每期 6 个红球按**数值从小到大**写入 `红1`—`红6`，蓝球写入独立列；即使来源网页的号码没有排序，也进行规范化。
3. **保留原始信息**：尽量保留网页原有字段（包括网站展示的模拟开机号），方便对照核查；期号按照升序排列。
4. **增加基础统计列**：红球和值、跨度、奇数/偶数个数、大/小数个数、连号组数、与上一期红球重号数、三区比例。
5. **频数汇总**：提供全历史、最近 100 期、最近 50 期、最近 30 期的红球和蓝球出现次数；这些只是对已有数据的描述，不代表未来概率。
6. **导出多种格式**：`.xlsx`、`.csv` 和 `.txt`；带有基本校验、错误日志及 Windows 一键启动脚本。

## Windows 安装和运行（推荐）

### 1. 安装 Python

建议使用 **Python 3.12**（此前已经在 Windows 的 Python 3.12 环境中验证启动方式）。安装时建议启用 **Add Python to PATH**；也可通过 Python Launcher `py` 启动。支持的主要依赖见 `requirements.txt`。

安装完，打开 **PowerShell** 或 **命令提示符（CMD）**，输入：

```powershell
py -3 --version
```

如果能显示 `Python 3.x.x`，再继续；如果提示找不到 `py`，尝试 `python --version`。

### 2. 下载并完整解压

在 GitHub 仓库点击 **Code → Download ZIP**，把压缩包**完整解压**到一个普通目录，例如 `D:\ssq-history-data-tool`。不要直接在压缩包预览窗口中双击 `run.bat`。

### 3. 双击运行

双击根目录中的 **`run.bat`**。脚本会自动：

- 检查 Python；
- 检查依赖，缺少时调用 `pip` 安装；
- 下载、校验并整理数据；
- 在根目录的 `双色球数据` 文件夹生成结果。

运行窗口会停留到你按键关闭。第一次运行需要网络连接；只有网页直连不可用时，才会尝试 Selenium 调用 Edge / Chrome（可能需要浏览器和驱动网络下载）。

### 4. 查看生成文件

```text
双色球数据/
├── 双色球历史数据.xlsx    # 推荐用 Excel 打开，含 5 张工作表
├── 双色球开奖记录.csv    # UTF-8 with BOM，方便 Excel 直接打开
├── 双色球开奖号.txt      # 每行一期的纯文本开奖号码
├── 双色球开机号.txt      # 第三方网页提供的模拟开机号
├── 运行日志.txt          # 运行记录 / 出错细节
└── 启动诊断日志.txt      # 由 run.bat 生成，便于排查启动问题
```

每次重新运行会更新同名结果文件。程序要求抓取达到最低完整性门槛（当前为 3000 期），避免将网页只返回的少量记录误当完整历史覆盖；**这一校验不等于保证数据绝对完整或实时**，请以最新期号和官方信息交叉核查。

## Excel 工作表说明

| 工作表 | 内容 |
| --- | --- |
| `开奖记录` | 正式历史奖号：期号、日期、升序红1—红6、蓝球及统计字段 |
| `开机号` | 第三方网站展示的**模拟**开机号，独立拆列与简单统计 |
| `原始数据` | 尽量保留网站页面的原始文字字段，便于检查来源 |
| `号码频率` | 全历史与近100/50/30期的红球、蓝球出现次数 |
| `说明` | 数据来源、生成时间、字段及使用说明 |

**统计口径**：和值 = 6 个红球之和；跨度 = 最大红球 − 最小红球；大数为 17—33，小数为 1—16；三区为 1—11 / 12—22 / 23—33；连号组数是长度 ≥ 2 的连续数字段数。`红1`—`红6` 表示**排序后的位置**，不是实际摇出顺序。

## 不使用批处理的方式

在项目根目录打开终端：

```powershell
py -3 -m pip install -r requirements.txt
py -3 ssq_downloader.py
```

Linux / macOS 可尝试使用 `python3` 和 `python3 -m pip`，但目前没有完成对应平台的现场运行验证，浏览器自动化的配置可能不同。

## 常见问题

**Q：双击 `run.bat` 一闪而过？** 先确认已完整解压，再在 CMD 中进入项目文件夹运行 `run.bat`；查看 `双色球数据/启动诊断日志.txt`。该版本末尾包含 `pause`，正常情况下不会立即关窗。

**Q：提示 `can't open file ... ssq_downloader_new.py`？** 这是历史版本实际出现过的启动问题：批处理所调用的脚本名与文件名不一致。现在统一为 `ssq_downloader.py`。请使用本仓库的**同一版本** `run.bat` 与 `.py`，不要混用旧文件。

**Q：Python 安装了，仍然显示缺少 requests / bs4 / openpyxl / selenium？** 检查启动的是不是同一个 Python 环境：`py -3 -m pip install -r requirements.txt`，再用 `py -3 -c "import requests,bs4,openpyxl,selenium; print('OK')"` 验证。

**Q：为什么没有生成文件？** 可能是网页结构改变、网络问题、浏览器驱动失败或历史记录数量未过校验门槛。查看 `运行日志.txt`；**不要把失败或只下载到几十期的数据当成完整历史**。

完整的排错说明及真实故障案例见 [安装和故障排除](docs/TROUBLESHOOTING.md)。
